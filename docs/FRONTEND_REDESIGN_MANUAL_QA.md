## 1. 安全的本机启动

在独立终端运行（沿用现有配置，不打印/复制密钥）：

```powershell
cd D:\实习日报\TravelAI\backend
.\.venv\Scripts\python.exe -m uvicorn app.api.main:app --host 127.0.0.1 --port 8000
```

```powershell
cd D:\实习日报\TravelAI\frontend
npm run build
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5173 --strictPort
```

打开 `http://127.0.0.1:5173`，复用历史计划 `ad39599a`，无需重新规划。5173 是现有后端 CORS 允许的端口；不要改用 4173 后把 CORS 失败误判为 UI 问题。

不要把设置接口或后端绑定到公网/不可信局域网；不要为了测试重新写 `.env`。截图避开配置密钥字段。结束后仅关闭自己启动的终端服务。

## 2. 真人读屏（NVDA + Chrome，或 Narrator + Edge）

记录：测试人____ 日期____ 浏览器/读屏版本____ 结果____ 证据____。

- [ ] Tab 首项为跳过导航；激活后主内容可读，只有一个 main。
- [ ] 导航语言选择、配置、助手、导出都有明确名称；装饰 SVG 不重复读出。
- [ ] 首页城市/停留天数/出发日期/交通/住宿/兴趣有名称及状态；空提交时焦点移到首个错误，错误可读且输入保留。
- [ ] 天气日期选中、图谱类型筛选、地图地点选中、日程折叠状态能被读出，不只依赖颜色。
- [ ] 设置、预算 Modal、聊天打开后焦点在弹层中；Tab/Shift+Tab 不穿透；Esc 关闭后回到触发器。
- [ ] 助手发送状态只简短播报；不重复播报整段历史；关闭重开仍能阅读已有消息。若要测试新回复，需测试人确认会消耗现有模型配额。
- [ ] 图谱列表及关联节点、文字路线和预算表格均可不使用 canvas 完成阅读。
- [ ] 导出准备/成功/失败与操作可理解；渲染阶段不可取消的原因明确。

遇到失败记录具体操作、读出的原文、期望原文和焦点位置，不把 AX 自动检查通过写成人工读屏通过。

## 3. 真机手机与软键盘

记录：机型____ 系统____ 浏览器____ 横/竖屏____ 结果____ 证据____。

Android 可用已有 Android SDK/adb 的 USB 端口转发（本轮未安装 adb）：

```powershell
adb reverse tcp:5173 tcp:5173
adb reverse tcp:8000 tcp:8000
```

手机浏览器访问 `http://127.0.0.1:5173`。其他平台需已批准的安全转发方案；不要直接把无认证设置接口暴露到网络。

- [ ] 竖屏首页、预算、日程、天气、图谱列表、地图列表无非必要横溢出，横滑轨道可操作。
- [ ] 手机横屏仍使用触屏输入规则，Enter 换行；发送按钮发送，不误提交中日文候选词。
- [ ] 聊天软键盘打开时输入/发送可见；关闭键盘后 Sheet 高度恢复，底部安全区不遮挡操作。
- [ ] 长消息可选中；上翻读旧消息不被新回复强制拉到底，“查看最新消息”可用。
- [ ] 设置与预算金额输入可编辑、可滚动；遮罩后背景不误滚；关闭回到原位置。
- [ ] light/dark/system、减少动态、字体放大下仍可用。关闭持续动画不影响状态反馈。
- [ ] 实际下载 PNG 能在手机相册/文件中打开；内容与现有计划一致。多文件下载若系统拦截，应告知/允许后核对，不能假装已全部保存。
